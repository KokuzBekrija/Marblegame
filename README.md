# Flag Marbles

Browser marble-elimination game where marbles are national flags.

## Start
```
npm install
npm run dev        # http://localhost:5173
npm test           # unit tests
npm run test:e2e   # needs: npx playwright install chromium
npm run build
```

Games (picked on the start screen): rotating ring with holes, and marble drop (flags fall through pegs and out through holes in the floor). See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

# Flag Marbles

Browser marble-elimination game where marbles are national flags.

## Start
```
npm install
npm run dev        # http://localhost:5173
npm test           # unit tests
npm run test:e2e   # needs: npx playwright install chromium
npm run build
```

Levels: rotating ring with holes (elimination), and a race through obstacles. See [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
